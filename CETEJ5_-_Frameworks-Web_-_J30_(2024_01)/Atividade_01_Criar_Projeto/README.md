# UTFPR — Frameworks Web — Pós-Graduação em Tecnologia Java

## Atividade 01 - Criar Projeto 

### Descrição da Atividade:

A atividade tem como objetivo a criação inicial de um projeto Angular, servindo como base para o desenvolvimento do sistema web ao longo da disciplina.

---

### O que deve ser realizado:

1. **Criar um novo projeto Angular** com o seguinte nome:

`frontend-funcionarios-departamentos`

2. Após a criação do projeto, **limpar o conteúdo padrão do arquivo** `src/app/app.component.html`, deixando-o vazio.

---

### Requisitos para a Entrega:

- O projeto deve ser compactado em um **arquivo `.zip`**.
- **Não incluir os seguintes diretórios** no `.zip`:
- `node_modules`
- `.angular`
- `.vscode`
- O arquivo `.zip` deve ser submetido **diretamente no ambiente Moodle**.
- **Não deixar a atividade em modo rascunho**. Somente tarefas enviadas de forma definitiva serão consideradas.

---

### Observações Importantes:

- **Atividades deixadas em modo rascunho não serão corrigidas.**
- **Serão desconsideradas as seguintes formas de envio:**
  - Capturas de tela (prints).
  - Arquivos em formatos diferentes de `.zip`, como `.pdf`, `.doc`, `.txt`, entre outros.

---

### Forma de Entrega:

- A submissão deve ser feita **exclusivamente no Moodle**.
- O projeto deve estar **compactado corretamente**, respeitando as instruções acima.
- Verificar se a tarefa foi enviada em definitivo, pois somente assim será considerada entregue no prazo.

---

**Importante:** Recomenda-se revisar cuidadosamente a estrutura do `.zip` antes do envio, garantindo que o projeto esteja íntegro e os diretórios proibidos tenham sido excluídos.
