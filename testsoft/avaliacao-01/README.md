# UTFPR — Teste de Software — Pós-Graduação em Tecnologia Java

## Avaliação da Disciplina

**Descrição da Avaliação:**

A avaliação consiste na especificação de um conjunto de casos de teste para um programa que recebe três valores inteiros representando os lados de um triângulo. Com base nesses valores, o programa deve determinar se o triângulo é equilátero, isósceles ou escaleno.

**Condição importante:**  
Para que os lados formem um triângulo válido, a soma de quaisquer dois lados deve ser maior que o terceiro lado.

---

### O que deve ser realizado:

- Desenvolver a classe Java que represente o triângulo, com validações para os lados e método para determinar o tipo do triângulo.
- Especificar e implementar um conjunto abrangente de **casos de teste automatizados utilizando JUnit**, cobrindo:
  - Triângulos válidos (equilátero, isósceles, escaleno).
  - Tratamento de exceções para lados inválidos (zero, negativos e soma inválida).
- Gerar e apresentar o **relatório de cobertura de código utilizando a ferramenta JaCoCo**, demonstrando o percentual de cobertura alcançado pelos testes.

---

### Forma de Entrega:

A atividade deve ser entregue em **formato `.pdf`**, contendo:

- A descrição dos casos de teste planejados.
- Trechos do código relevantes (classe e testes).
- O relatório ou resumo do percentual de cobertura de código obtido com JaCoCo.

O documento deve ser claro, organizado e apresentar fundamentação técnica adequada.
