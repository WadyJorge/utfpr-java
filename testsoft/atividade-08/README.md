# UTFPR — Teste de Software — Pós-Graduação em Tecnologia Java

## Atividade 08 - Teste de Sistema (Parte 2)

**Descrição da Atividade:**

Esta atividade tem como objetivo aprofundar a compreensão sobre a execução de testes de sistema em múltiplos browsers e estratégias para automatização e gerenciamento desses testes.

---

### Enunciado:

O participante deve responder, de forma clara e objetiva, aos seguintes questionamentos:

1. O que deve ser feito no código para permitir que a mesma bateria de testes de sistema possa ser executada em diferentes browsers?
2. É uma boa prática definir estaticamente, em diversas partes do código, qual browser será utilizado? Justifique.
3. Faça uma breve pesquisa sobre a ferramenta **BrowserStack** e apresente uma síntese sobre suas funcionalidades e benefícios.

---

### Forma de Entrega:

A atividade deve ser entregue em **formato `.pdf`**, contendo as respostas aos três itens propostos. As respostas devem ser organizadas com clareza, objetividade e linguagem técnica adequada.
