# UTFPR — Teste de Software — Pós-Graduação em Tecnologia Java

## Atividade 04 - Mock Objects (Parte 1)

**Descrição da Atividade:**

Esta atividade tem como objetivo a aplicação de testes com **objetos mock** utilizando o framework **Mockito** em conjunto com **JUnit**, no contexto da implementação de um jogo de dados (Craps).

---

### Enunciado:

O participante deve implementar, em Java, a lógica de um **jogo de Craps**, conforme especificado no anexo disponibilizado na plataforma da disciplina.

A seguir, deve-se aplicar testes unitários com o uso de **objetos mock criados com Mockito**, de modo a isolar dependências e garantir a verificação de comportamentos esperados.

---

### Requisitos de Implementação:

1. Implementar a lógica do **jogo de Craps** conforme descrito no anexo `teste_com_objetos_mock-java.pdf`.
2. Utilizar **Java puro** para a implementação da lógica principal.
3. Criar os testes unitários utilizando **JUnit** em conjunto com **Mockito**.
4. O uso de objetos mock deve ser aplicado para simular comportamentos e validar interações específicas.
5. A implementação deve focar na clareza e na separação entre regras de negócio e testes.

---

### Forma de Entrega:

A entrega deve ser feita em **um único arquivo `.pdf`**, contendo:

- O código-fonte completo das classes do jogo;
- O código dos testes unitários com Mockito e JUnit;
- Toda a formatação do código deve estar adequada à leitura.
