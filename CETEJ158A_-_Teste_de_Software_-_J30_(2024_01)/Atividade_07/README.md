# UTFPR — Teste de Software — Pós-Graduação em Tecnologia Java

## Atividade 07 - Teste de Sistema (Parte 1)

**Descrição da Atividade:**

Esta atividade tem como objetivo abordar conceitos fundamentais relacionados ao **teste de sistema** e ao **teste de aceitação**, evidenciando suas características e diferenças.

---

### Enunciado:

O participante deve responder, de forma clara e objetiva, aos seguintes questionamentos:

1. O que é o **teste de sistema**?
2. O que é o **teste de aceitação**?
3. Qual a **diferença entre teste de sistema e teste de aceitação**?

---

### Forma de Entrega:

A atividade deve ser entregue em **formato `.pdf`**, contendo as respostas aos três itens propostos. As respostas devem apresentar linguagem técnica adequada, organização e clareza.
