# UTFPR — Teste de Software — Pós-Graduação em Tecnologia Java

## Atividade 09 - Teste de Serviços Web

**Descrição da Atividade:**

Esta atividade tem como objetivo analisar os desafios encontrados na automação de testes para serviços web, com base no guia de uso do framework **Rest-Assured**.

---

### Enunciado:

O participante deve consultar o guia de uso do Rest-Assured disponível em:  
[https://github.com/rest-assured/rest-assured/wiki/Usage](https://github.com/rest-assured/rest-assured/wiki/Usage)

Em seguida, deve citar e explicar **três desafios** que ainda podem ser encontrados na automação de testes de serviços web.

---

### Forma de Entrega:

A atividade deve ser entregue em **formato `.pdf`**, contendo as três descrições dos desafios encontrados, organizadas com clareza e fundamentação técnica.
