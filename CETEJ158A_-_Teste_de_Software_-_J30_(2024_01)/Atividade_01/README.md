# UTFPR — Teste de Software — Pós-Graduação em Tecnologia Java

## Atividade 01 - Introdução ao Teste de Software

**Descrição da Atividade:**

Responder, com base em pesquisa, os seguintes itens introdutórios sobre teste de software:

1. Explicar as **fases do teste**:
   - Teste de unidade
   - Teste de integração
   - Teste de sistema

2. Explicar as **técnicas de teste**:
   - Técnica funcional
   - Técnica estrutural

3. Explicar o **critério de teste funcional**:
   - Particionamento em classes de equivalência

**Forma de Entrega:**

- A atividade deve ser entregue em **formato `.pdf`**, contendo as respostas aos itens acima.
