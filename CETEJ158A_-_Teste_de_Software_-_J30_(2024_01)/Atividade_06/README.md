# UTFPR — Teste de Software — Pós-Graduação em Tecnologia Java

## Atividade 06 - Teste de Integração

**Descrição da Atividade:**

Esta atividade tem como objetivo reforçar os conceitos relacionados aos **testes de integração**, abordando suas características, técnicas e boas práticas no contexto de aplicações Java, especialmente no uso de banco de dados.

---

### Enunciado:

O participante deve responder, de forma clara e objetiva, aos seguintes questionamentos teóricos sobre testes de integração:

1. Quais são as **diferenças entre testes de unidade e testes de integração**?
2. **Como limpar o banco de dados** durante a execução dos testes de integração?
3. Quais são as **vantagens e desvantagens de utilizar scripts** para popular o banco de dados durante os testes de integração?
4. **Devemos testar até métodos simples**, como por exemplo salvar um usuário utilizando o Hibernate, nos testes de integração?

---

### Forma de Entrega:

A atividade deve ser entregue em **formato `.pdf`**, contendo as respostas aos quatro itens propostos. As respostas devem ser organizadas com clareza, objetividade e linguagem técnica adequada.
